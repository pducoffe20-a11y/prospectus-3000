# 架构摘要

## 契约矩阵

| 领域       | 输入                    | 输出                      | 不变量                           |
| ---------- | ----------------------- | ------------------------- | -------------------------------- |
| 规范化     | `EvidenceClaim`         | 原文和出处 + 独立可比较值 | 不改写输入                       |
| 来源独立性 | 两条声明 + 显式来源谱系 | 带原因代码的判断          | 未知谱系不算独立                 |
| 佐证       | 声明集合 + 来源谱系     | 确定性关系                | 循环、派生、摘要/页面不提升佐证  |
| 冲突       | 声明集合 + 可选显式解决 | 七类冲突结果              | 权威不删除矛盾；未解决时保留双方 |
| 推理       | 事实声明 + 六类推理步骤 | 深冻结运行产物            | 行动连接决策和证据；结果保持假设 |
| 变化解释   | 两个只读运行产物        | 证据及推理差异            | 不修改任何历史运行               |

## 关键边界

现有 `EvidenceClaim` 没有发布者、原始来源或引用图，因此来源独立性由核对层的显式谱系元数据提供，不能从 URL 或标题猜测。现阶段产物在内存和文件级不可变；数据库层不可变性不在本里程碑中。
